# Exemples Python – Formation POO

Cette série d'exemples illustre chaque chapitre de `theorie/` en Python.

## Comment exécuter

Depuis la racine du repo :

```bash
cd exemple
python 01_intro.py
python 02_classe.py
python 03_heritage.py
python 04_interfaces.py
python 05_encapsulation.py
python 06_getters_setters.py
python 07_static.py
python 08_instanceof.py
```

Chaque script est autonome et affiche le résultat dans la console.
